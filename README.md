# ERP-project

A full-stack ERP project with a Node.js/Express backend and a React frontend.

## Project structure

- backend/: API server, routes, models, middleware, and database config
- frontend/: React application UI and client-side services

## Getting started

1. Install backend dependencies
   - cd backend
   - npm install
2. Install frontend dependencies
   - cd frontend
   - npm install
3. Start the backend and frontend apps as needed for local development.

## Notes

This repository is set up to store both the application backend and frontend together in a single GitHub project.
